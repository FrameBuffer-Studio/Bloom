# Текстуры

**Текстура** - это готовая картинка, которая лежит в памяти, как наклейка в альбоме. Её можно много раз «приклеить» на холст: в любое место, любого размера, с подкраской и прозрачностью.

```text
 текстура 4×2          холст
 ┌──────┐              ┌──────────────────┐
 │ ▓▓░░ │    Draw →    │   ▓▓▓▓░░░░       │
 │ ▓▓░░ │   ×2 размер  │   ▓▓▓▓░░░░       │
 └──────┘              │   ▓▓▓▓░░░░       │
                       │   ▓▓▓▓░░░░       │
                       └──────────────────┘
```

Текстуры живут в модуле `Bloom.Texture`.

```lua
local Texture = Bloom.Texture
```

## Создание текстуры

### `Texture.New(width, height, pixels, copy_pixels?)`

**Что делает:** делает текстуру из своего буфера с пикселями.

| Имя | Тип | Что это |
|-----|-----|---------|
| `width`, `height` | `number` | Размер в пикселях (округляется вниз) |
| `pixels` | `buffer` | Ровно `width * height * 4` байт: R, G, B, A для каждого пикселя, строчка за строчкой |
| `copy_pixels` | `boolean?` | По умолчанию буфер **копируется**. `false` - взять твой буфер без копии |

```lua
local pixels = buffer.create(2 * 2 * 4)
buffer.writeu32(pixels, 0, Color4.New32Bit(255, 0, 0))
buffer.writeu32(pixels, 4, Color4.New32Bit(0, 255, 0))
buffer.writeu32(pixels, 8, Color4.New32Bit(0, 0, 255))
buffer.writeu32(pixels, 12, Color4.New32Bit(255, 255, 255))

local checker = Texture.New(2, 2, pixels)
```

**Все исходы:**

- ✅ Текстура создана.
- 📋 `copy_pixels` не указан или `true` - у текстуры своя копия, и твой буфер можно дальше менять без последствий.
- 🔗 `copy_pixels = false` - текстура использует **твой** буфер. Если ты его поменяешь, поменяется и текстура. Это экономит память.
- 🚫 Ширина или высота меньше 1 - ошибка `Texture.New expects positive dimensions`.
- 🚫 Размер буфера не равен `width * height * 4` - ошибка `Texture.New expects width * height * 4 RGBA bytes`.

### `Texture.FromEditableImage(editable_image)`

**Что делает:** копирует пиксели из `EditableImage` в новую текстуру.

```lua
local tex = Texture.FromEditableImage(myEditableImage)
```

**Все исходы:**

- ✅ Текстура того же размера, что и картинка.
- 🔒 Сама картинка не меняется и не удаляется.
- ℹ️ Если потом поменять картинку, текстура останется старой: это копия.

### `Texture.FromContent(content)`

**Что делает:** загружает картинку из Roblox (например, по `rbxassetid://`) и делает из неё текстуру.

> [!WARNING]
> Эта функция **ждёт** загрузки (yield). Вызывай её не внутри `RenderStepped`, а заранее, при запуске.

```lua
local tex = Texture.FromContent(Content.fromUri("rbxassetid://1234567890"))
```

**Все исходы:**

- ✅ Картинка загрузилась - текстура готова. Временная `EditableImage` сразу удаляется.
- 🚫 Картинка не твоя (Roblox разрешает загружать только картинки создателя игры или группы) - ошибка от Roblox.
- 🚫 Выключен `Allow Mesh / Image APIs` - ошибка от Roblox.
- 🧠 Закончилась память - ошибка `Texture.FromContent: EditableImage memory budget is exhausted`.
- 🚫 Не удалось прочитать пиксели - ошибка передаётся дальше, а временная картинка всё равно удаляется.

## Работа с текстурой

### `texture:GetPixel(x, y)`

**Что делает:** узнаёт цвет пикселя текстуры. Координаты, как и везде, с 1.

**Все исходы:**

- ✅ Возвращает цвет.
- ✂️ Дробные координаты округляются вниз.
- 0️⃣ За пределами текстуры - `0`.
- 0️⃣ Текстура удалена - `0`.

### `texture:Destroy()`

**Что делает:** освобождает память текстуры.

**Все исходы:**

- ✅ Буфер заменяется пустым, `texture.destroyed = true`.
- 🚫 Рисовать удалённую текстуру нельзя: будет ошибка `Cannot draw a destroyed Texture`.
- 🔁 Повторный вызов безопасен.

### Поля текстуры

| Поле | Что это |
|------|---------|
| `texture.width`, `texture.height` | Размер |
| `texture.pixels` | Буфер пикселей |
| `texture.destroyed` | `true`, если текстура удалена |

## Рисование текстуры

### `canvas:DrawTexture(texture, x, y, width?, height?, options?)`

**Что делает:** переносит текстуру на холст.

| Имя | Тип | Что это |
|-----|-----|---------|
| `texture` | `Texture` | Что рисовать |
| `x`, `y` | `number` | Где будет левый верхний угол |
| `width`, `height` | `number?` | Какого размера нарисовать. По умолчанию - как у текстуры |
| `options` | `DrawOptions?` | Дополнительные настройки (смотри таблицу ниже) |

**Настройки `options`:**

| Поле | По умолчанию | Что делает |
|------|--------------|------------|
| `source_x`, `source_y` | `1`, `1` | Откуда в текстуре начинать вырезать кусочек |
| `source_width`, `source_height` | вся текстура | Какого размера кусочек вырезать |
| `tint` | белый `0xFFFFFFFF` | Подкраска: каждый канал умножается на канал этого цвета |
| `opacity` | `1` | Прозрачность от 0 (невидимо) до 1 (как есть) |
| `blend` | `true` | `true` - смешивать с фоном по прозрачности. `false` - просто заменить пиксели |

**Примеры:**

```lua
canvas:DrawTexture(tex, 10, 10)

canvas:DrawTexture(tex, 10, 10, tex.width * 3, tex.height * 3)

canvas:DrawTexture(tex, 50, 50, nil, nil, {
	tint = Color4.New32Bit(255, 120, 120),
	opacity = 0.5,
})

canvas:DrawTexture(spriteSheet, 100, 100, 32, 32, {
	source_x = 33,
	source_y = 1,
	source_width = 32,
	source_height = 32,
})
```

Последний пример - это **спрайт-лист**: одна большая картинка со множеством кадров. Из неё вырезается кадр размером 32 × 32, который начинается с пикселя 33.

**Все исходы:**

- ✅ Текстура нарисована. Растягивание и сжатие делаются методом «ближайшего соседа»: пиксели становятся квадратиками, без размытия. Для пиксель-арта это как раз то, что нужно.
- ✂️ Координаты и размеры округляются вниз.
- ✂️ Кусочек `source_*` зажимается внутри текстуры: вылезти за край нельзя.
- ✂️ Результат обрезается по холсту и окошку.
- 🎨 `tint` белый и `opacity = 1` - пиксели не перекрашиваются, и рисование идёт быстрее.
- 🎨 `opacity` меньше 0 считается за 0, больше 1 - за 1.
- 🧱 `blend = false` - пиксели заменяются целиком, вместе с прозрачностью. Это самый быстрый режим для непрозрачных картинок.
- 🙈 `width` или `height` равны 0 или меньше - ничего не происходит.
- 🙈 Место целиком за холстом - ничего не происходит.
- 💤 Холст удалён - ничего не происходит.
- 🚫 Текстура удалена - ошибка `Cannot draw a destroyed Texture`.

> [!TIP]
> Создавай текстуры **один раз** при запуске, а в каждом кадре только рисуй их. Создание текстуры копирует много памяти.
