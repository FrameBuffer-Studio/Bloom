# Шрифты и текст

Чтобы писать на холсте буквы, Bloom нужен **шрифт**. Шрифт в Bloom - это картинка-шпаргалка, на которой нарисованы все буквы (она называется **атлас**), и табличка, где на этой картинке лежит каждая буква.

```text
 атлас:  ┌───┬───┬───┬───┬───┐
         │ A │ B │ C │ D │ … │   DrawText("CAB") → берём C, потом A, потом B
         └───┴───┴───┴───┴───┘                    и наклеиваем их по порядку
```

Шрифты живут в `Bloom.Font`.

```lua
local Font = Bloom.Font
```

## Способ 1. Из файла `.ttf`

Bloom сам умеет читать файлы шрифтов TrueType (`.ttf`) и рисовать из них атлас.

### `Font.FromString(font_data, pixel_size, charset?, options?)`

**Что делает:** превращает байты `.ttf`-файла (в виде строки) в шрифт.

| Имя | Тип | Что это |
|-----|-----|---------|
| `font_data` | `string` | **Сырые байты** файла `.ttf`. Не Base64, а именно байты |
| `pixel_size` | `number` | Размер букв в пикселях, от 4 до 128 |
| `charset` | `string?` | Какие буквы подготовить. По умолчанию - все печатные символы ASCII (английские буквы, цифры и знаки) |
| `options` | `Options?` | `spacing` - добавочное расстояние между буквами, `fallback` - код буквы-замены (по умолчанию `?`) |

```lua
local font = Font.FromString(fontBytes, 18)

local russian = Font.FromString(fontBytes, 16,
	" АБВГДЕЁЖЗИЙКЛМНОПРСТУФХЦЧШЩЪЫЬЭЮЯабвгдеёжзийклмнопрстуфхцчшщъыьэюя0123456789.,!?-"
)
```

**Все исходы:**

- ✅ Шрифт готов. Буквы рисуются белыми с мягкими краями, поэтому их можно подкрасить любым цветом.
- ✅ Буква `?` добавляется **всегда**, даже если её нет в `charset`: она нужна как замена для незнакомых букв.
- ✅ Одинаковые буквы в `charset` не мешают: каждая готовится один раз.
- 🔤 Русские и другие буквы работают, если они есть в самом шрифте и в `charset`. `charset` пишется в UTF-8, как обычная строка Luau.
- 🚫 Строка короче 12 байт или вообще не строка - ошибка `Font.FromString expects a non-empty binary font string`.
- 🚫 `pixel_size` меньше 4 или больше 128 - ошибка `Font.FromBuffer pixel_size must be between 4 and 128`.
- 🚫 Это не TrueType (например, `.otf` с CFF, `.woff`, `.woff2`) - ошибка `Font supports TrueType-outline TTF files only; CFF/WOFF/WOFF2 are not supported`.
- 🚫 В файле нет нужных таблиц - ошибка `TTF is missing a required TrueType table`.
- 🚫 Нет таблицы Unicode (cmap format 4 или 12) - ошибка `TTF has no supported Unicode cmap (format 4 or 12)`.
- 🚫 Файл обрезан или испорчен - ошибка `Invalid or truncated TrueType font: ...`.
- 🚫 Странные размеры шрифта - ошибка `Invalid TrueType metrics`.
- 🚫 Слишком много букв или слишком крупный размер (атлас больше 1024 × 1024) - ошибка `Font atlas is too large; reduce pixel_size or the charset`.
- 🔹 Если буквы из `charset` нет в самом шрифте, вместо неё в атлас попадёт «неизвестный» знак этого шрифта. Обычно это пустой квадратик.

> [!WARNING]
> `FromString` - **тяжёлая** работа: нужно нарисовать каждую букву по кривым. Делай это **один раз** при запуске, а не в каждом кадре.

> [!NOTE]
> Не поддерживаются: CFF-шрифты (обычно `.otf`), WOFF и WOFF2, переменные шрифты и составные буквы, которые прикрепляются по точкам. Такой шрифт сначала переделай в обычный статический `.ttf`, например в программе FontForge.

### `Font.FromBuffer(font_buffer, pixel_size, charset?, options?)`

**Что делает:** то же самое, но байты лежат в `buffer`, а не в строке.

**Все исходы:** такие же, как у `FromString`. Если буфер короче 12 байт - ошибка `Font.FromBuffer expects a non-empty binary font buffer`.

### Как достать байты `.ttf` в Roblox

Roblox не умеет читать файлы с диска. Есть два способа.

**А. Положить шрифт в ModuleScript.** Маленькая программа на Python превращает `.ttf` в модуль Luau:

```python
import sys

data = open(sys.argv[1], "rb").read()
chunks = []
for start in range(0, len(data), 4096):
    part = data[start:start + 4096]
    chunks.append('"' + "".join(f"\\x{byte:02x}" for byte in part) + '"')

with open("FontData.luau", "w") as output:
    output.write("return table.concat({\n" + ",\n".join(chunks) + "\n})\n")
```

```lua
local fontBytes = require(game.ReplicatedStorage.FontData)
local font = Bloom.Font.FromString(fontBytes, 18)
```

**Б. Скачать на сервере.** Включи **HttpService** в настройках игры, скачай файл через `HttpService:GetAsync(url)` и передай игроку как `buffer` через `RemoteEvent`. На клиенте используй `Font.FromBuffer`.

> [!TIP]
> Выбирай маленькие шрифты или оставляй в них только нужные буквы (в FontForge это называется subset). Так модуль будет меньше.

## Способ 2. Свой атлас

Если у тебя уже есть картинка со всеми буквами (например, пиксельный шрифт), сделай шрифт сам.

### `Font.New(atlas, glyphs, line_height, options?)`

| Имя | Тип | Что это |
|-----|-----|---------|
| `atlas` | `Texture` | Картинка со всеми буквами |
| `glyphs` | `table` | Где лежит каждая буква. Ключ - сама буква (`"A"`) или её код (`65`) |
| `line_height` | `number` | Высота строчки в пикселях |
| `options` | `Options?` | `spacing` и `fallback` |

**Каждая буква (glyph) описывается так:**

| Поле | Обязательное? | Что это |
|------|---------------|---------|
| `x`, `y` | да | Левый верхний угол буквы в атласе (с 1) |
| `width`, `height` | да | Размер буквы в атласе |
| `xoffset` | нет | Насколько сдвинуть букву вправо при рисовании |
| `yoffset` | нет | Насколько сдвинуть букву вниз от верха строчки |
| `xadvance` | нет | На сколько шагнуть вправо после буквы. По умолчанию - `width` |

```lua
local atlas = Bloom.Texture.FromEditableImage(fontImage)
local pixelFont = Font.New(atlas, {
	A = { x = 1, y = 1, width = 5, height = 7, xadvance = 6 },
	B = { x = 7, y = 1, width = 5, height = 7, xadvance = 6 },
	[" "] = { x = 1, y = 1, width = 0, height = 0, xadvance = 4 },
	["?"] = { x = 13, y = 1, width = 5, height = 7, xadvance = 6 },
}, 8)
```

**Все исходы:**

- ✅ Шрифт создан. Ключи-буквы превращаются в коды. Если ключ - строка из нескольких букв, берётся только первая.
- ✅ `line_height` округляется вниз.
- 🚫 Атлас уже удалён - ошибка `Font.New expects a live texture atlas`.
- 🚫 `line_height` равен 0 или меньше - ошибка `Font.New expects a positive line height`.
- 🔗 Атлас теперь **принадлежит** шрифту: `font:Destroy()` удалит и его.

## Рисуем текст

### `canvas:DrawText(font, text, x, y, color?, scale?)`

**Что делает:** пишет текст на холсте.

| Имя | Тип | Что это |
|-----|-----|---------|
| `font` | `Font` | Каким шрифтом |
| `text` | `string` | Что написать (UTF-8) |
| `x`, `y` | `number` | Левый верхний угол текста |
| `color` | `number?` | Цвет. По умолчанию белый |
| `scale` | `number?` | Увеличение. `2` - в два раза больше. По умолчанию `1` |

**Возвращает:** `width, height` - сколько места занял текст в пикселях.

```lua
local w, h = canvas:DrawText(font, "Привет!\nВторая строчка", 10, 10, Color4.New32Bit(255, 220, 0), 2)
```

**Все исходы:**

- ✅ Текст нарисован и смешан с фоном по прозрачности.
- ↩️ `\n` - переход на новую строчку.
- ⇥ `\t` - отступ шириной в 4 пробела.
- ❓ Буквы нет в шрифте - рисуется буква-замена (`fallback`, по умолчанию `?`).
- 🙈 Нет ни буквы, ни замены - буква пропускается, и места под неё нет.
- 📏 Масштаб увеличивает буквы методом «ближайшего соседа»: при `scale = 2` каждый пиксель становится квадратиком 2 × 2.
- ✂️ Текст за краем холста или окошка обрезается.
- 0️⃣ Холст или шрифт удалены - ничего не рисуется, возвращается `0, 0`.
- 🚫 `text` не строка (например, число) - ошибка `DrawText expects a string`. Используй `tostring(число)`.
- 🚫 `scale` равен 0 или меньше - ошибка `DrawText expects a positive scale`.
- 🚫 В строке сломанный UTF-8 - ошибка Luau от `utf8.codes`.

### `Font.MeasureText(font, text, scale?)`

**Что делает:** узнаёт размер текста, **не рисуя** его. Правила те же, что у `DrawText`.

**Возвращает:** `width, height`.

```lua
local w, h = Font.MeasureText(font, "Играть", 2)
local x = math.floor((canvas.res_x - w) / 2) + 1
canvas:DrawText(font, "Играть", x, 50, nil, 2)
```

Так текст ставится ровно по центру.

**Все исходы:**

- ✅ Возвращает размер. Высота = количество строчек × высота строчки × масштаб.
- ℹ️ Ширина считается по шагам букв (`xadvance`), поэтому она может быть на пиксель-два шире видимых букв.

### `font:Destroy()`

**Что делает:** удаляет атлас шрифта.

**Все исходы:** ✅ атлас удалён, и `DrawText` с этим шрифтом больше ничего не рисует. 🔁 Повторный вызов безопасен.

## Поля шрифта

| Поле | Что это |
|------|---------|
| `font.texture` | Атлас |
| `font.glyphs` | Буквы (код → glyph) |
| `font.line_height` | Высота строчки |
| `font.spacing` | Добавочное расстояние между буквами |
| `font.fallback` | Код буквы-замены |
| `font.destroyed` | `true`, если шрифт удалён |
