## Три правила, которые стоит запомнить сразу

1. **Клеточки считаются с единицы.** Самый левый верхний пиксель - это `(1, 1)`, а не `(0, 0)`.
2. **Края входят в фигуру.** Прямоугольник от `1` до `10` - это 10 пикселей, а не 9.
3. **Нарисовал - покажи.** Рисование меняет только память. Чтобы картинка появилась на экране, вызови `canvas:Update()` или `canvas:EndFrame()`.
