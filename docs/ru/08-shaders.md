# Шейдеры

**Шейдер** - это волшебный фильтр. Ты даёшь ему кусочек холста, а он смотрит на **каждый** пиксель по очереди и решает, каким этот пиксель станет. Это как фильтры в камере телефона: «чёрно-белый», «ярче», «наоборот».

```text
 до:  ▓▓░░▒▒   →  Invert  →  после:  ░░▓▓▒▒
```

> [!WARNING]
> Шейдеры Bloom работают на **процессоре**, а не на видеокарте. Шейдер на весь холст 1024 × 1024 вызывает твою функцию **больше миллиона раз**. Применяй шейдеры к маленьким кусочкам и не в каждом кадре.

Шейдеры живут в `Bloom.Shader`.

```lua
local Shader = Bloom.Shader
```

## Готовые шейдеры

### `Shader.Invert()`

**Что делает:** выворачивает цвета наизнанку: чёрный становится белым, красный - голубым. Прозрачность не меняется.

```lua
canvas:ApplyShader(Shader.Invert(), 1, 1, canvas.res_x, canvas.res_y)
```

### `Shader.Grayscale()`

**Что делает:** делает картинку чёрно-белой. Яркость считается так, как её видит глаз (формула Rec. 709): зелёный кажется ярче синего. Прозрачность не меняется.

### `Shader.Brightness(amount?)`

**Что делает:** делает ярче или темнее. `amount = 1` - как было, `2` - в два раза ярче, `0.5` - темнее, `0` - чёрный.

```lua
local bright = Shader.Brightness(1.3)
canvas:ApplyShader(bright, 1, 1, 100, 100)

canvas:ApplyShader(bright, 1, 1, 100, 100, { amount = 0.7 })
```

**Все исходы:**

- ✅ Каждый канал умножается на `amount` и обрезается сверху на 255.
- 🔹 `amount` не указан - будет 1.
- 🔹 `amount` меньше 0 считается за 0.
- 🔹 В `uniforms` вместо числа лежит что-то другое - используется 1.

## Свой шейдер

### `Bloom.CreateShader(name, callback, uniforms?)`

Это то же самое, что `Shader.New(name, callback, uniforms?)`.

**Что делает:** создаёт твой собственный фильтр.

| Имя | Тип | Что это |
|-----|-----|---------|
| `name` | `string` | Имя, чтобы не запутаться (не пустое) |
| `callback` | `function` | Функция, которая вызывается для каждого пикселя |
| `uniforms` | `table?` | Настройки по умолчанию, которые получает функция |

**Функция `callback` получает:**

| Аргумент | Что это |
|----------|---------|
| `x`, `y` | Где пиксель на холсте (с 1) |
| `u`, `v` | Где пиксель внутри кусочка: от 0 (левый/верхний край) до 1 (правый/нижний) |
| `color32` | Текущий цвет пикселя |
| `uniforms` | Настройки |

**И должна вернуть:** новый цвет (`number`) или `nil`, если пиксель не нужно менять.

```lua
local gradient = Bloom.CreateShader("Gradient", function(x, y, u, v, color32, uniforms)
	local red = math.floor(u * 255)
	local blue = math.floor(v * 255)
	return Color4.New32Bit(red, 0, blue, 255)
end)

canvas:ApplyShader(gradient, 1, 1, 200, 200)
```

```lua
local threshold = Bloom.CreateShader("Threshold", function(_, _, _, _, color32, uniforms)
	local r, g, b, a = Color4.Unpack(color32)
	local value = if (r + g + b) / 3 >= uniforms.level then 255 else 0
	return Color4.New32Bit(value, value, value, a)
end, { level = 128 })
```

**Все исходы при создании:**

- ✅ Возвращает шейдер `{ name, callback, uniforms, enabled = true }`.
- 🚫 `name` не строка или пустая строка - ошибка `Shader.New expects a name`.
- 🚫 `callback` не функция - ошибка `Shader.New expects a callback`.

**Как выключить шейдер, не удаляя его:** `myShader.enabled = false`. После этого `ApplyShader` будет его пропускать.

## Применение шейдера

### `canvas:ApplyShader(shader, x0, y0, x1, y1, uniforms?)`

**Что делает:** пропускает прямоугольник холста через шейдер.

| Имя | Тип | Что это |
|-----|-----|---------|
| `shader` | `Shader` | Какой фильтр |
| `x0, y0, x1, y1` | `number` | Углы прямоугольника (включительно, в любом порядке) |
| `uniforms` | `table?` | Настройки на этот раз. Если указаны, **полностью заменяют** настройки шейдера |

**Возвращает:** `number` - сколько пикселей обработано.

**Все исходы:**

- ✅ Каждый пиксель прошёл через функцию. Возвращается количество пикселей.
- 🎬 До работы запускается стадия `beforeShader`, после - `afterShader`.
- 🔹 Функция вернула `nil` - пиксель остался прежним.
- ✂️ Прямоугольник обрезается по холсту и окошку.
- 0️⃣ Прямоугольник целиком за окошком - возвращает `0`, а стадии не запускаются.
- 0️⃣ `shader.enabled = false` - возвращает `0`.
- 0️⃣ Холст удалён - возвращает `0`.
- 📏 Прямоугольник шириной в 1 пиксель - `u` всегда 0. Высотой в 1 пиксель - `v` всегда 0.
- 💥 Функция выдала ошибку - ошибка **вылетает наружу** из `ApplyShader`. Пиксели, которые успели обработаться, уже изменены, а плитки помечены грязными. Стадия `afterShader` не запускается.
- 💥 Функция вернула не число (например, строку) - ошибка Luau при записи в буфер.

## Как сделать шейдер быстрым

1. **Ничего не создавай внутри функции:** никаких `{}`, `Vector2.new`, `Color3.new`, `function() end`. Всё нужное создай снаружи.
2. **Применяй к маленькому кусочку.** Нужно затемнить кнопку - бери прямоугольник кнопки, а не весь экран.
3. **Не применяй каждый кадр**, если картинка не меняется.
4. **Возвращай `nil`** для пикселей, которые не меняются: так меньше записей в память.

```lua
local function slow(_, _, _, _, color32)
	local parts = { Color4.Unpack(color32) }
	return Color4.New32Bit(parts[1], parts[2], parts[3], parts[4])
end

local function fast(_, _, _, _, color32)
	local r, g, b, a = Color4.Unpack(color32)
	return Color4.New32Bit(r, g, b, a)
end
```
